# Tempo user guide

## Start a focus round

1. Pick **Standard**, **Deep Work**, or **Quick Sprint**, or enter custom durations in Settings.
2. Add a task in the Tasks panel. An estimate is the number of focus rounds you expect to spend on it.
3. Click the task to make it current.
4. Select **Start focus**. The progress ring and timer show the remaining time.

The main button changes to **Pause focus** while the timer runs. **Reset** returns the current phase to its configured duration and pauses it.

## Breaks and cycles

Tempo starts with a short break after a focus round. After the configured number of focus rounds, it schedules a long break. The default cycle is four focus rounds followed by a 15-minute break.

Turn on **Auto-advance** to start the next phase automatically. Leave it off if you prefer to decide when to begin the next focus or break.

## Tasks and estimates

Use the task form to add a title and an estimated number of Pomodoros. Each completed focus round advances the task's progress. Completing the estimate marks the task finished; you can still add another task for the next piece of work.

## Presets and settings

- **Standard:** 25-minute focus, 5-minute short break
- **Deep Work:** 50-minute focus, 10-minute short break
- **Quick Sprint:** 15-minute focus, 3-minute short break

Settings also include the long-break length, the number of rounds before a long break, sound, browser notifications, XP celebrations, and Auto-advance.

## History, streaks, and rewards

The Daily history panel records completed rounds and focus minutes by day and calculates your current streak. Completed focus rounds award XP. XP raises your level and unlocks badges for milestones such as a first focus, a consistent streak, a finished task, and a five-round day.

The daily goal progress is shown in the Focus XP panel. Reward notifications can be disabled with **XP celebrations**.

## Focus mode

Use **Focus mode** in the top bar to hide the supporting panels and keep the timer and current task in view. Use the same button again to return to the full dashboard.

## Notifications and sound

Enable **Browser notifications** in Settings and allow notifications when the browser asks. A notification can alert you when a focus or break phase ends while you are working in another tab. **Completion sound** plays a short tone locally when a phase ends.

## Install Tempo

Click **Install** in the top bar. If the browser exposes its native install prompt, Tempo opens it. Otherwise, the button opens a short guide for Chrome, Edge, Safari, and Firefox. Installation is available on supported browsers over HTTPS or on `localhost`.

## Keyboard shortcuts

| Key | Action |
| --- | --- |
| `Space` | Start or pause the current phase |
| `R` | Reset the current phase |
| `N` | Focus the new-task field |

Shortcuts are ignored while typing in a text or number field.

## Export and import

- **Export JSON** saves settings, tasks, history, and gamification progress.
- **Export CSV** saves the daily history as a spreadsheet-friendly file.
- **Import backup** restores a JSON export after you select a file.

Import replaces the current saved Tempo data in that browser. Keep a fresh export before importing an older backup.
